# Apple Passwords

The `autofill` skill uses the official iCloud Passwords extension to fill saved logins in Chrome without exposing saved passwords to the assistant. It applies to Apple Passwords prompts; website verification follows the normal authorized login workflow.

Install `apple-passwords@package-manager` in Codex or Claude. Native Passwords unlock uses the separately approved `macbook@package-manager` credential broker. Run `npm test` to validate the package.
